# VibeSnap

VibeSnap is a web-based digital photobooth designed to capture and customize your moments instantly. Capture photos, apply aesthetic filters, add stickers, and export your memories as high-quality JPGs or animated GIFs directly from your browser.

![Preview](https://res.cloudinary.com/dgleeitj5/image/upload/v1777534360/5_gnxaza.jpg)

## Key Features

* **Real-time Capture**: Seamless photo sessions using your device's camera.
* **Custom Layouts**: Multiple grid options with customizable frame colors.
* **Interactive Stickers**: Personalize your photos with drag-and-drop aesthetic elements.
* **High-Resolution Export**: Save your captures in premium JPG and GIF formats.

## Getting Started

Ensure you have [Node.js](https://nodejs.org/) and [pnpm](https://pnpm.io/) installed on your machine.

### 1. Clone the Repository
```bash
git clone https://github.com/23withv/photobooth-web.git
cd photobooth-web
```

### 2. Install Dependencies
```bash
pnpm install
```

### 3. Run Development Server
```bash
pnpm dev
```

Once started, navigate to `http://localhost:3000` in your web browser to view the application.
